# FF Painel — projeto Android

Projeto inicial em Kotlin com três áreas:
1. Painel LEGIT: sugestões editáveis de sensibilidade e orientações de HUD.
2. Painel VISUAL: checklist de configuração.
3. Painel de TREINO: exercício simples de tempo de reação.

O app não se conecta ao Free Fire, não injeta código no jogo e não oferece trapaças.

## Como gerar o APK
1. Abra a pasta `FF_Painel_Android` no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Se necessário, instale o Android SDK 35 pelo SDK Manager.
4. Vá em Build > Build Bundle(s) / APK(s) > Build APK(s).
5. O APK de depuração será gerado em `app/build/outputs/apk/debug/`.

Este é o código-fonte do projeto, não um APK já compilado.
